# Java Pair Sum

This Java program finds all pairs in an array whose sum equals a given target.

## Example

Input:

```java
int[] arr = {0,1,2,3,4,5,6,8};
int target = 10;
```

Output:

```
Pair found: 2, 8
Pair found: 4, 6
```

## Time Complexity

- Brute Force: O(n²)

## Language

- Java
